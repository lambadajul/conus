# PLC Tag Explorer

PLC Tag Explorer is a lightweight .NET application for browsing PLC tags, searching by name, filtering by category, and exporting results to CSV.

## Features

- Browse PLC tags
- Fast search
- Filter by type
- Filter by group
- CSV export
- Statistics
- Console table output

## Project Structure

```
src/
 ├── Config
 ├── Data
 ├── Models
 ├── Services
 └── Utils
```

## Build

```bash
dotnet build
```

## Run

```bash
dotnet run
```
